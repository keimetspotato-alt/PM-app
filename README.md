# 未来を見据える家計簿

家計の記録と将来の収支シミュレーションを開発するための環境です。
現時点では開発用の初期画面のみです。収支入力、保存、予測、ログインは未実装です。

## 起動

Node.js 24系（確認済み: 24.21.0）、npm、Gitを使用します。

```powershell
cd kakeibo
npm ci
npm run dev
```

起動後、ターミナルに表示されたURLを開きます。標準は http://127.0.0.1:5173 です。
終了は Ctrl+C。依存パッケージはインストール済みなので、通常は `npm run dev` だけで起動できます。

## コマンド

- `npm run dev`: ローカル開発サーバー
- `npm run check`: 型チェック、コード検査、テスト、整形確認、ビルド
- `npm run test:watch`: テストの監視実行
- `npm run format`: コード整形
- `npm run build`: 配布用ファイルをdistに生成

Vitestは導入済みです。機能は未実装のためテストファイルはまだありません。
`npm test` はテストがない場合も終了できます。計算実装時にテストを追加してください。

## 構成

- `src/App.tsx`: 初期画面
- `src/domain/`: 画面から独立した収支計算用の場所
- `src/index.css`, `src/App.css`: スタイル
- `package-lock.json`: 依存バージョンの固定

React + TypeScript + Viteを採用。コード検査はOxlint、整形はPrettier、テストはVitestです。
Viteの公式セットアップ: https://vite.dev/guide/

## 今後の開発

外部サービスやデータベースの契約は不要です。環境変数の秘密情報は `.env.local` に置き、Gitへ登録しません。`VITE_` で始まる変数はブラウザに公開されるので秘密情報を入れないでください。
