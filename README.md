# PM-app — セルフマネジメント

お金・予定・タスク・目標を一か所に集めるアプリ。現在は家計簿MVPです。

## 使える機能

- 基準日の資産登録、資産合計の表示
- 基準日以降の収入・支出の記録、一覧、削除
- 毎月の手取り収入・支出を設定し、1〜30年後の残高をグラフと年次表で表示
- 翌月以降の一時支出を予測に反映
- ブラウザへの自動保存、JSONバックアップの書き出し・復元

## 計算の前提

現在残高 = 基準日の資産合計 + 記録した収入 - 現金・銀行での支出 - 引き落とし済みのカード請求。
カード利用は利用日の支出に集計し、残高は引き落とし時に一度だけ減らします。利用記録には対応する請求を指定します。
カード請求で毎月の支出内訳を選ぶと、引き落とし月の選択した予算全額を請求額に置き換えます。一部だけ確定した場合は、月額内訳を分割してから対応付けてください。
未対応の請求は月額予算に追加されます。請求のうち利用記録のない差額は、引き落とし月の未分類支出として集計します。
予測は現在残高から当月以前の未払いカード請求を引き、翌月以降に「毎月の収入 - 対応付けで調整した毎月の支出 - 未払いカード請求 - 該当月の予定支出」を加算します。
今月の残りの収支、運用益、インフレ、追加の税金計算は含みません。
過去になった予定は予測から外れます。実際に支出したときは収支記録へ登録してください。
金額は整数の円。登録した項目は編集・削除できます。
引き落とし済みの請求と利用記録は、請求を未払いに戻してから編集します。請求に紐づく内訳や利用記録には削除制限があります。
既存の収支は従来の残高計算を維持します。カード利用分は手動で支払方法と請求を編集してください。旧方式の支払済み記録も自動変換しません。
臨時支出予定との重複、カード会社の明細との照合は自動検出しません。口座ごとの引き落とし・振替は未実装です。

## 保存

データは利用中のブラウザのlocalStorageに保存します。サーバー送信・端末間同期・認証は未実装です。
ブラウザのデータ削除で失われるため、設定画面から定期的にJSONバックアップを保存してください。
保存先はURLごとに分かれます。普段は `http://127.0.0.1:5173/` を使用してください。
読めない既存データは上書きせず、自動保存を停止します。

## 開発

Node.js 24系、npm、Gitを使用します。

```powershell
cd kakeibo
npm ci
npm run dev -- --port 5173 --strictPort
```

- `npm run check`: 型検査・コード検査・テスト・書式検査・ビルド
- `npm run test:watch`: 計算テストの監視
- `npm run format`: 整形
- `npm run build`: distへのビルド

React + TypeScript + Vite / Vitest / Oxlint / Prettier。
`src/features/finance/domain/finance.ts` に計算処理と保存形式の検証を分離しています。
